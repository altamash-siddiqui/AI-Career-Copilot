# 🤖 AI Career Copilot

An AI-powered career assistant designed to help users plan, manage, and track their career journey.

AI Career Copilot provides career-focused tools such as:

- 📄 Resume Analysis
- 🎯 ATS Score Checking
- 🎤 Interview Preparation
- 🗺️ Career Roadmap
- 📊 Career Dashboard
- 📈 Roadmap Progress Tracking
- ⭐ Favorite Career Management
- 🔍 Career Record Search
- ✏️ Career Record Update
- 🗑️ Career Record Deletion
- 📜 Career History
- 📁 CSV Career Export
- 📝 Career Report Export
- 💾 Career Data Backup
- 🔄 Career Data Restore
- 🔐 User Authentication
---
## 🚀 Features

### 🔐 User Authentication

Users can:

- Register a new account
- Login with existing credentials
- Access user-specific career data

---

### 🗺️ Career Roadmap

Users can select a career and receive a structured roadmap.

Supported career paths include:

- 🤖 AI
- 🌐 Web Development
- 🐍 Python
- 📊 Data Science

Each roadmap contains multiple learning steps that can be completed individually.

---

### 📈 Roadmap Progress Tracking

Users can track their roadmap progress through:

- Completed steps
- Remaining steps
- Progress percentage
- Visual progress bar
- Career completion status

Career status:

- ⏳ Not Started
- 🚀 In Progress
- 🏆 Completed

---

### 📊 Career Dashboard

The dashboard provides an overview of the user's career progress.

It displays:

- Current career information
- Total career records
- Average roadmap progress
- Completed roadmap steps
- Career statistics
- Most popular career
- Individual career progress
- Visual progress bars
- Career status

---

### 📄 Resume Analysis

The project includes a resume analysis feature designed to help users identify areas that can be improved in their resume.

---

### 🎯 ATS Score

The ATS feature helps evaluate resume content from an Applicant Tracking System perspective.

---

### 🎤 Interview Preparation

Users can prepare for interviews through career-focused interview preparation functionality.

---

### ⭐ Favorite Careers

Users can mark careers as favorites and view their favorite career records separately.

---

### 🔍 Career Search

Users can search their stored career records to quickly find specific career information.

---

### ✏️ Career Record Management

Users can:

- Update career records
- Delete career records
- View career history
- Manage multiple career records

---

### 📁 Data Export

Career information can be exported for external use.

Supported formats include:

- CSV
- TXT career reports

---

### 💾 Backup & Restore

The application provides career data backup and restore functionality to help protect user information.
